# aws-windows-ec2-assessment
Windows EC2 deployment and RDP system information assessment



AWS Windows EC2 Assessment
Objective

Create a Windows virtual machine on AWS EC2, connect using Remote Desktop Protocol (RDP), and display system information using Command Prompt.

Technologies Used
AWS EC2
Windows Server
Remote Desktop Protocol (RDP)
Windows Command Prompt
Steps Completed
Launched a Windows Server EC2 instance.
Configured secure RDP access.
Connected to the Windows desktop using RDP.
Executed the systeminfo command in Command Prompt.
Captured screenshots of the deployment and system information.

Result

Security

Private keys and passwords must not be uploaded to GitHub.
